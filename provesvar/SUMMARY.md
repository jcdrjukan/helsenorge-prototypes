# Prøvesvar

Static HTML prototype for the Helsenorge **Prøvesvar** (test results) service. Started 2026-10-08 as an empty shell; content will be built up partly from Figma.

## Current state
- `index.html`: the Helsenorge chrome only: header with profile bar, "Forside" breadcrumb (goes nowhere yet), Språk/Language switcher, a PageHeader rebuilt from the live Prøvesvar page's markup (title "Prøvesvar" and a favoritter star copied from Gravid that toggles and is remembered in the browser), the real ingress ("Her finner du svar på prøver og undersøkelser, for eksempel blodprøver, røntgen, MR eller CT."), a HelpExpanderStandalone "Velg om du vil få varsel om prøvesvar" (from the live markup; opens draft text: "Du får ikke automatisk varsel når et prøvesvar er klart. Vil du ha varsel, kan du slå det på i varselinnstillingene dine."), a Spacer (s), then a sticky white Tabs section breaking out to full width (from the live markup): **Prøvesvar** has the filter row ("Finn ..." FilterButton, inert; "N prøvesvar" count; a working "Sortering:" select by date, område or rekvirent, default newest first) and an outline PanelList of 9 white Panels (område title, rekvirent, "Prøvedato", borderless "Se resultater" with ChevronRight, not linked yet) using the live page's test data; **Analyseoversikt** (navigate by prøvesvartype) is a placeholder. Then a Spacer (s); the feedback form "Hvor fornøyd er du med tjenesten Prøvesvar?" (five plum face radios, Misfornøyd … Veldig fornøyd; selecting one marks it, nothing is submitted); Spacer (l); the title2 "Personvern for Prøvesvar"; Spacer (m); a line LinkList with "Logg over bruk" and "Personverninnstillinger" (not linked); then the black footer, and the desktop phone frame.
- `resultat.html?id=N` (detail page for all 9 results, rendered from a `RESULTATER` object; every "Se resultater" on the list links to its own id): breadcrumb back to Prøvesvar; language picker (real Dropdown + SingleSelect, marks the choice and announces it; no translation); eyebrow (Laboratoriemedisin, or Patologi for Cytologi — assumed); title with help trigger (inert, no star); Duolist Prøvedato / Rekvirert av / Utført av (DictionaryTriggers); blueberry HighlightPanel; an ExpanderList per result with the first expander ("Prøvesvar (n)" or "Prøvesvar") open. Undersøkelse blocks are built from rows (Undersøkelse, Laboratorieresultat/Resultat, Referanseområde, Måleenhet, Funn, Prøvemateriale, Mengde, Kommentar, Vurdering, Aktuell problemstilling…), optional "Vis undersøkelseshistorikk" (inert), optional avviksmarkør ("(over øvre referanseområde)"), and for two-sided reference ranges a static SVG copy of the live Highcharts reference-range chart. Words in {braces} in the data get a dotted-underline word explanation from one ORDFORKLARINGER glossary (drafts); explanation boxes open below the whole text so sentences aren't split. Collapsed expanders whose content wasn't supplied (Detaljer om prøvesvar, Prøvemateriale (n), Resistensbestemmelse (5), Tilleggsinformasjon (n>0)) open to "Innholdet her er ikke med i prototypen ennå."
- The chrome and design tokens are copied from `gravid/avslutt.html`. No shared CSS with other prototypes.
- `favicon.svg` copied from `prover-og-undersokelser/` ("P" on blueberry).
- Deployed at https://helsenorge-provesvar.netlify.app (Netlify site `helsenorge-provesvar`, created 2026-10-08).
